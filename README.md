# HarmFour

Four-bar live harmonica desk for unfinished choruses.

Bedroom producers and AI-music finishers already have a vocal and a kit. The chorus still has no human figure on top, so the song sits open. Session players write four live bars — FluidR3 harmonica, steel-string bed, acoustic bass — then you bounce a WAV onto the chorus.

Live samples only. No oscillators. Audio never leaves the tab.

Yesterday's public ship was RiffFour (overdriven electric riff). AirFour, shipped earlier the same day, is strategic space. HarmFour is the missing reed figure.

| **HarmFour** | Four bars of **live harmonica** so the chorus has a human figure |

## Loop

1. Pick a groove (Porch Light, County Wire, Dust Road, Freight Yard, Amber Lot).
2. Pick a figure (train chord, blue line, call and answer, held wail, cross harp, last-bar tag).
3. Hear the hole: the chorus without the harmonica.
4. Hear the full pass: four bars of hole, then the four-bar harp.
5. Bounce a WAV of the figure and copy the punch list.
